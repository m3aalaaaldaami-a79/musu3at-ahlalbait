# موسوعة اهل البيت

تم إنشاء هذا المشروع بواسطة **HTML2APK Studio** لتحويل تطبيق الويب (HTML) إلى تطبيق أندرويد (APK) باستخدام **Capacitor 6** و **GitHub Actions**.

## معلومات التطبيق
- **اسم التطبيق:** موسوعة اهل البيت
- **معرف الحزمة (Package ID):** `com.studio.myapp`
- **الإصدار:** `1.0.0` (كود الإصدار: `1`)
- **اتجاه الشاشة:** `portrait`
- **لون شريط الحالة:** `#0f172a`

## خطوات بناء وتحميل ملف APK عبر GitHub
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع جميع ملفات هذا المشروع إلى المستودع (تأكد من وجود الملف `.github/workflows/build-apk.yml`).
3. انتقل إلى تبويب **Actions** داخل المستودع، وانتظر من 3 إلى 5 دقائق حتى يكتمل البناء بنجاح (علامة الصح الخضراء ✅).
4. اضغط على العملية المكتملة، ثم حمّل ملف **`myapp-debug-apk`** من قسم **Artifacts** في الأسفل.
5. فك الضغط وستجد ملف `app-debug.apk` جاهزاً للتثبيت على هاتفك الأندرويد.
